Учебный проект по управлению ИТ-продуктом, группа ИСИТ-05.

- Белобородова Арина — интервью и обратная связь по пилоту.
- Забель Арсений — лидер команды и координация общего результата.
- Яньков Иван — таблица и инструкция.

## Вывод интервью и решение команды

Из десяти ответов восемь содержат конкретный эпизод трудности при распределении домашних дел; два описывают работающий порядок. Это основание проверить проблему и решение в пилоте, но не оценка распространённости среди всех студентов.

Первая версия проекта — общий список домашних дел на квартиру: задача, ответственный, срок и статус. План проверки — шесть квартир на 14 дней. Критерий продолжения: не менее четырёх квартир выполняют заранее заданный сценарий, записи вносят как минимум два жильца. Учёт расходов в первую версию не входит.

## Как загрузить работу

1. Откройте каждый итоговый HTML-файл в браузере и нажмите «Выгрузить Markdown».
2. Сохраните пять экспортов как `S1.md`, `S2.md`, `S3.md`, `S4.md`, `S5.md`. Экспорт RICE для столовой сохраните отдельно как `RICE_столовая.md`.
3. Добавьте эти Markdown-файлы, `Product_Book_505.md` и этот README в репозиторий GitVerse. HTML-шаблоны можно положить в папку `рабочие-шаблоны`.
4. Откройте ссылки из README и убедитесь, что все файлы доступны преподавателю.
5. Отправьте одно письмо на `Mamonov.VG@rea.ru`: в теме укажите номер учебной группы, в тексте — фамилии и имена трёх участников и ссылку на репозиторий.
